## This website

The site you're reading is itself a project. It's built with Next.js and TypeScript, and every article, project and note is a plain Markdown file with a small block of metadata at the top. Adding a post means adding one file:

```markdown
---
title: A new post
summary: One or two sentences.
category: engineering-technology
date: 2026-10-11
draft: true
---

The post starts here.
```

Pages are generated ahead of time, so there's no database or server to maintain.
